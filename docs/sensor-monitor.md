# 传感器监视器

这个页面只读取无人机数据，不发送解锁、油门、起飞或其他控制命令。运行电脑需要连接无人机 Wi-Fi；此时电脑没有互联网不影响读取。

## 启动

当前已临时使用 `//` 注释停用自动读取，并停止本次运行的监视器服务。需要恢复时，取消 `scripts/sensor_monitor.html` 中 `window.addEventListener('pageshow', start);` 与 `SensorMonitor.start();` 两行的注释，再按以下步骤启动服务并刷新页面。这项停用仅涉及电脑监视器，无需重新烧录。

在项目目录的 CMD 中运行：

```bat
cd /d D:\1work_UAV\Tiny-Drone-main
py -3 scripts\monitor_sensors.py
```

如果 `py` 的关联不正常，也可以直接使用已经安装的 Python：

```bat
D:\python\python.exe scripts\monitor_sensors.py
```

浏览器打开 `http://127.0.0.1:8765/`。在运行命令的窗口中按 `Ctrl+C` 停止。

已有旧监视器占用端口时，先停止旧窗口，或者用 `--port 8766` 启动，然后打开 `http://127.0.0.1:8766/`。

默认读取 `http://192.168.26.28/api/poshold`。地址不同时可指定：

```bat
py -3 scripts\monitor_sensors.py --url http://192.168.26.28/api/poshold --port 8765
```

只在本机提供页面；HTTP 请求不使用系统代理。页面最快每 100 ms 读取一次，上次请求结束后才发起下一次，连接变慢时不会叠加请求。页面刷新不是飞控的采样频率。

## 页面读数

| 区域 | 内容与单位 | 如何理解 |
|---|---|---|
| 融合估算 | 高度 m、机身前向/左向速度 m/s、横滚/俯仰/航向 ° | 飞控的 Kalman 融合结果。速度由世界坐标系转为机身坐标系，正值分别表示向前、向左；不是某一个传感器直接测得的速度。 |
| PMW3901 光流 | 原始 dx/dy counts、安装轴映射后 dx/dy、帧间隔、SQUAL、motion、快门及图像统计 | 原始 dx/dy 保留传感器输出方向；映射后 dx/dy 与飞控使用的机体轴一致。位移计数不是米，也不是 m/s；融合接收状态表示该帧是否被用于估算。 |
| IMU | 原始加速度/角速度 counts、温度原始值；驱动加速度 g、角速度 °/s、温度 °C | 原始值使用芯片轴；驱动数据使用安装映射、校准和滤波后的机身轴，不能逐轴直接比较。静止时加速度仍包含约 1 g 的重力，不应要求各轴全为零。 |
| VL53L1X 测距 | 距离 mm、测量有效、读取成功、状态码、信号率/环境光率 MCPS、sigma mm | 距离是朝下测量方向上到物体的距离，尚未做机身倾斜修正。读取失败时不显示测量值；读取成功但测量无效时，保留原始读数并标明无效。 |
| 气压计 | 原始气压/温度 ADC、气压 hPa、温度 °C、换算海拔 m | 气压换算海拔受环境气压影响，与相对地面高度不同；应先看气压和原始 ADC 是否稳定。 |
| 磁力计 | 原始 XYZ counts、驱动磁场 XYZ gauss | 设备未安装或未启用时明确显示状态。电机、电源线和附近金属会影响磁场。 |

每个传感器会显示是否收到采样、数据是否新鲜、采样距今时间；光流、IMU、气压计和磁力计还显示累计帧数或采样次数。看到「过期」时，显示的只是最后读数，不代表当前状态。连接失败会清空数值，并在曲线中留空，避免把旧值误认为实时值。

飞控状态无效时，融合速度、高度和姿态不显示数值；独立有效的测距仍可显示。页面的「Kalman 已启用 / 未启用」表示是否选用了 Kalman 估算器，不是它的健康诊断。IMU 后端暂不可用时，独立测距仍按自己的采样状态显示。

如果显示「当前固件未提供，需烧录新增接口」，说明电脑页面已更新，但飞机上运行的固件还没有这些诊断字段。需要把包含新增接口的固件烧录一次；之后仅启动电脑监视器不需要重复烧录。旧固件已有的融合高度、速度、姿态、光流仍可查看。`—` 表示缺失或无效数据，不会用 0 代替。

## 静止排查

拆桨、电机保持停止，机身放稳，底部传感器无遮挡且下方有纹理。先看光流原始/映射后的 dx/dy 是否围绕零、测距是否有效，再看 IMU 是否稳定，最后与融合速度对照。机身静止而 dx/dy 接近零、融合速度持续增加，说明需要进一步检查重力补偿、姿态与融合偏差，不能仅凭这一现象断定光流坏了。停桨静止测试不能替代飞行验证。

